====================Folder	Role for frontend================

app/	Manage routing and protected routes.
assets/	Store images, icons, and custom fonts used in the frontend.
components/	Store reusable UI components, such as buttons, modals, and tables.
features/	Organize business features, such as products, suppliers, orders, and checkout.
hooks/	Store reusable custom React hooks.
layouts/	Define shared page structures, such as the admin sidebar and storefront navbar.
services/	Configure API communication with the Laravel backend.
utils/	Store reusable helper functions, such as price and date formatting.
